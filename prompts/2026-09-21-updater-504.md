# Correção do auto-updater 0.2.1 — erro HTTP 504

## Objetivo
Evitar falhas intermitentes HTTP 504 durante o download de atualizações Electron distribuídas pelos assets do GitHub Release.

## Skills/documentos lidos
- `AGENTS.md`
- `app/desktop/electron/updater.cjs`
- `app/electron-builder.json`
- `app/desktop/artifacts/stable*.yml`

## Código e configuração inspecionados
- Fluxo IPC de verificação, download, retry de startup e instalação em `updater.cjs`.
- Provider GitHub e canal `stable` em `electron-builder.json`.
- Manifestos e assets publicados no release `v0.2.1`.

## Diagnóstico
O manifesto `stable-mac.yml` aponta para assets existentes e o GitHub responde a Range requests. O erro ocorre durante o download diferencial, que depende do blockmap e de várias requisições parciais.

## Alteração proposta
- Desabilitar o download diferencial no `electron-updater`, forçando um download completo do artefato publicado.
- Manter os retries de verificação existentes e os estados de erro visíveis.
- Não alterar provider, canal, versão, dados da aplicação ou permissões.

## Critérios de aceite
- Build desktop concluído.
- Lint, typecheck e testes concluídos.
- Manifestos continuam apontando para assets existentes.
- O updater não usa blockmap para o download da atualização.

## Segurança e rollback
- Nenhum segredo ou credencial será alterado.
- Rollback: remover a configuração adicionada em `updater.cjs` e rebuildar.

## Testes
- `npm run lint`
- `npm run typecheck`
- `npm test -- --run`
- `npm run build:desktop:web`
- Verificação HTTP dos manifestos e assets do release.
